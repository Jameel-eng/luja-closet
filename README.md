# LuJa Closet

Lupita & Jamil's shared closet.

- **Lupita / Jamil** — photograph each piece once, tag it Home / Normal outside / Formal hangout. The main color is detected from the photo.
- **Style me** — pick an occasion (and optionally lock a piece, e.g. a shirt) and get outfits scored on color harmony, contrast, patterns and occasion.
- **Matching** — couple looks: one outfit for each of you that work together side by side.
- **Daily** — an outfit diary with a day streak.

Everything is stored on the device (IndexedDB), including photos. Use **Settings → Download backup** to move data to another phone.

No build step: plain HTML/CSS/JS, served by GitHub Pages.
